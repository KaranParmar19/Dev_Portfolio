## ✦ Key Architecture & Highlights

### 01. The Scrapbook Journey
- **Tactile Chronicles**: Multi-layered scrapbook journals, hand-taped notes, polaroid artifacts, and animated sticker mechanics.
- **Certificate Inspection**: High-fidelity stamp credentials with interactive hover reveals and credential links.
- **Paper-Tear Transitions**: Physics-based, midnight-slate diagonal page-tear reveals inspired by real paper mechanics.

### 02. The Engineering Workbench (Toolkit)
- **4 Specialized Modules**:
  - `01 // Client Workbench`: React 19, Next.js 16, TypeScript, Tailwind CSS, Fabric.js canvas.
  - `02 // Autonomous & Cloud`: LangChain, RAG architectures, OpenAI/Claude tool-calling, Docker, AWS, CI/CD.
  - `03 // Server & Distributed`: Node.js, Express, Microservices, Redis, WebSockets, Kafka, GraphQL, BullMQ.
  - `04 // Languages & Systems`: Python, PostgreSQL, MongoDB, C++, Java, Linux Bash.
- **Interactive Skill Pills**: Hover tooltip roles, custom accent glows, category filtering, and real-world usage tags.

### 03. Kinetic Polish & Motion Design
- **Lenis Smooth Scroll**: Inertia-based virtual scrolling integrated seamlessly with GSAP `ScrollTrigger`.
- **Liquid Typography**: Dynamic SVG wave displacement heading animations.
- **Live Metrics**: Server-side LeetCode submission heatmap and real-time activity metrics.

## ✦ Local Development

Clone and spin up the development environment locally:

```bash
# 1. Clone repository
git clone https://github.com/KaranParmar19/Dev_Portfolio.git

# 2. Navigate to project root
cd Dev_Portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## ✦ Production Build

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run start
```
