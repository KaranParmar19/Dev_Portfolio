## ✦ Overview

This portfolio is an interactive playground engineered from the ground up to showcase full-stack development, modern interface aesthetics, and physics-based animations. Built on the cutting-edge Next.js 16 App Router and React 19, it integrates custom WebGL shaders, kinetic typography, dynamic page transitions, and real-time telemetry.

---

## 🛠️ Tech Stack & Architecture

- **Core Framework**: [Next.js 16](https://nextjs.org/) (App Router, Server & Client Components)
- **UI Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom typography variables
- **Motion & Physics**: 
  - [GSAP 3](https://greensock.com/gsap/) & ScrollTrigger
  - [Framer Motion](https://www.framer.com/motion/)
  - [Lenis](https://lenis.darkroom.engineering/) for normalized inertia smooth scroll
  - [Three.js](https://threejs.org/) & custom WebGL shaders
- **Typography**: Handcrafted font pairings featuring Neulis Neue, Futura Bold, Syne, Space Grotesk, Caveat, and Excalifont
- **Telemetry**: Custom Discord webhook analytics engine with edge-header geolocation and bot filtering

---

## ⚡ Key Highlights & Interactive Features

- **Kinetic Section Transitions**: Interactive paper-tear and curtain transitions during in-app navigation with reduced-motion fallbacks.
- **Elastic Section Morphing**: Custom SVG bézier curves dynamically responsive to scroll velocity for organic boundary transitions between sections.
- **Interactive Toolkit**: Categorized skills and tooling showcased with official SVG iconography, tactile hover states, and Excalifont typography accents.
- **Smart Viewport Blur**: Progressive backdrop-filtered scroll blur that automatically fades out at the bottom of the viewport to keep footer metadata razor sharp.
- **Live LeetCode Activity Sync**: Dedicated Next.js API route that fetches, parses, and renders live problem-solving metrics and 13-month contribution heatmaps.
- **Zero-Intrusive Analytics**: Completely cookie-free visitor telemetry delivering real-time visitor alerts, device breakdown, and referrer insights straight to Discord.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/KaranParmar19/Dev_Portfolio.git
cd Dev_Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables (optional)
Create a `.env.local` file in the root directory:
```env
# Optional: Discord webhook URL for invisible visitor notifications
DISCORD_WEBHOOK_URL="https://discord.com/api/webhooks/your_id/your_token"
```

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
